Responsabilidad del servicio (SRP)

Pagos es el microservicio responsable de administra los datos y la lógica del dominio de Pagos del caso caso06 (ViajaMejor). dentro del caso caso06 (ViajaMejor). Sus datos se persisten en una base de datos H2 en memoria (una por microservicio) y queda aislado del resto de la solución para garantizar bajo acoplamiento y alta cohesión.

Endpoints

MétodoRutaDescripción
GET/api/pagosLista todos los recursos
GET/api/pagos/{id}Obtiene un recurso por id
POST/api/pagosCrea un recurso
PUT/api/pagos/{id}Actualiza un recurso
DELETE/api/pagos/{id}Elimina un recurso

Ejemplo rápido

curl -X POST http://localhost:8080/api/pagos \
  -H "Content-Type: application/json" \
  -d '{"nombre":"Crear recurso"}'
curl http://localhost:8080/api/pagos
